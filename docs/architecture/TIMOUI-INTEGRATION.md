# TimoUI — подключение к общему стандарту

Статус: архитектурное решение утверждено 2026-11-23; разработка и внедрение НЕ подтверждены.

## Единственный источник архитектурных правил
https://github.com/julcapp/soft-ice-platform/blob/main/docs/architecture/TIMOUI-INTEGRATION.md

## Применение в этом репозитории
Учебные карточки, расписание и тесты как UI над текущей системой слушателей и прогресса.

## Обязательные условия
- Использовать общие TimoUI-контракты и адаптеры, не создавать собственную конкурирующую библиотеку Telegram Widgets.
- Существующие API, авторизация, пользователи, бизнес-данные, основные ветки и рабочие сценарии не меняются без отдельной проверенной миграции.
- Виджеты только UI/transport, сервер контролирует права, идемпотентность и источник данных.
- Inline HTML widgets оставлять экспериментальными до официальной поддержки в Telegram production; предусмотреть обычный inline и Mini App fallback.
- В этой фиксации НЕ выполняются изменения runtime, production, платежей, инфраструктуры или ветвления.
- Любые изменения: актуальный SDK/API audit, тесты, безопасность, контролируемый выпуск и откат.

## Учёт задач
Перед реализацией сверить текущую ветку и код с каноническим стандартом; отмечать прогресс в соответствующем GitHub issue/PR, не фиксировать непроверенное как выполненное.
