# Редактируемые сценарии консультанта PracticAI

Согласовано пользователем 2 ноября 2026 года.

Консультант работает по сценариям без внешних API. CRM позволяет создавать вопросы, ключевые фразы, ответы, направление и включать или выключать сценарии. Проверка несохранённого сценария не меняет ответы на сайте.

Диалог сохраняет выбранное направление при уточняющих вопросах, даёт подтверждённые условия и предлагает форму заявки с выбранным направлением. Заявка сохраняется существующим API только с согласием; успех показывается после сохранения с номером заявки. Неизвестные условия передаются менеджеру. Цена курса бухгалтеров 19 990 ₽, пять занятий, доступ три месяца, начало в первый понедельник месяца, 17:30 по Томску, оплата 100%. Остальные дни и итоговый документ не утверждены.

Варианты: внешняя модель зависит от доступности провайдера; ответы в коде требуют разработчика; выбран вариант сценариев в MySQL с редактором CRM. Удаление или выключение сценария исключает его из публичных ответов. HTML в ответах отображается как текст.

Изменения фиксируются в GitHub и синхронизируются с чистой копией на Home-Boss для GitHub Desktop. Публикация использует существующий Hostland workflow.
