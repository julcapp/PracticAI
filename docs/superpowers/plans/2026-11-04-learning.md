# Learning foundation implementation plan

> Implement inline using superpowers:executing-plans.

**Goal:** Подготовить базу и проверяемый серверный фундамент продажи курсов.
**Architecture:** Изолированный модуль Node.js/MySQL. Проверенный объект платежа
поступает в транзакцию, блокирующую заказ; доступ, документы и outbox фиксируются вместе.
**Tech Stack:** Node.js, mysql2, node:test, MySQL 5.7+.
**Spec:** docs/superpowers/specs/2026-11-04-learning.md

## Global Constraints
- Три календарных месяца по Томску; хранение UTC.
- Без изменений production, реальных платежей и отправки писем.
- Без секретов в репозитории.

## Review Focus
- Конец месяца и високосный год: срок не перескакивает на следующий месяц.
- Дубликаты и параллельные webhook: один доступ и одно задание письма.
- Поддельный статус/сумма/магазин/режим test: отказ без доступа.
- Ошибка документальной записи: полный rollback, retry возможен.
- Истёкший или отозванный доступ: закрытый материал недоступен.
