# «Ваш Финэксперт» — Финансовый паспорт предприятия: продуктовая концепция
Дата: 2026-11-22. Статус: концепция, НЕ опубликовано на сайте.
Коммерческий сервис: **Ваш Финэксперт**.
Управленческий модуль: **Персональный финансовый навигатор**.
Внутреннее имя платформы «Кирюша» не использовать во внешнем бизнес-позиционировании.

## Основная ценность
«Узнайте финансовую историю бизнеса по официальным данным — и подключите собственный учёт для управленческих решений».
Первый шаг: регистрационная карточка и доступная опубликованная финансовая отчётность. Второй: персональная управленческая аналитика по данным клиента.

## Первый экран и воронка
1. «Введите ИНН предприятия или ИП» + выбор ЮЛ/ИП.
2. Подтянуть доступные ФНС-реквизиты: название, ОГРН/ОГРНИП, статус, основной и дополнительные ОКВЭД, руководитель для ЮЛ.
3. Телефон и сайт — опционально, отсутствующие значения оставлять пустыми; пользователь может подтвердить или добавить.
4. Показать опубликованные данные за доступные годы (для организаций при наличии) и видимые ограничения.
5. Дать понятный пример диаграммы динамики доходов/расходов, рентабельности — только если значения сопоставимы.
6. CTA: «Подключить Персональный финансовый навигатор» — загрузить данные 1С/Excel/банка для подробного ДДС, ОПиУ и бюджетов.
7. Для аутсорсеров: отдельная регистрация бухгалтерской компании + число обслуживаемых ООО/ИП и сотрудников.

## Обязательно пояснять
ФНС не даёт внутреннюю оборотно-сальдовую ведомость предприятия по публичному ИНН. Для ИП годовая БФО может отсутствовать. Данные публичной отчётности исторические и не равны текущему финансовому состоянию. Указывать источник, отчётный год, дату обновления, единицы измерения. Не обещать автодоступ к корпоративному телефону, сайту и непрозрачным сведениям.

Запрещено заявлять автоматическое формирование достоверной ОСВ из открытых данных.

## Продуктовые метрики
Доля успешного поиска ФНС; доля карточек с подтверждёнными полномочиями; доля доступных годовых отчётов; переход из паспорта к загрузке собственных данных; переход к платной подписке; доля ошибочных извлечений (требует эталонного теста).
Никаких реальных данных клиентов или секретов в GitHub.
