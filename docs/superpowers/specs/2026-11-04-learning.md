# Учебный модуль PracticAI
Согласовано: ЮKassa, три календарных месяца от подтверждённой оплаты,
письмо со ссылкой, хранение курсов, уроков, материалов, заказов и документов.
Основной сайт и действующая база не изменяются. Concrete CMS остаётся редактором
публичных страниц; учебный модуль использует отдельную MySQL-базу и серверную проверку доступа.
Первый этап: схема MySQL, модель срока доступа, проверка платежа и атомарное
создание доступа, событий, документальных записей и задания отправки письма.
Денежные суммы хранятся в копейках. Время БД — UTC, календарный срок — по Томску.
31-е число при отсутствии такого дня в конечном месяце заменяется последним днём месяца.
Клиентский redirect не подтверждает оплату; webhook вызывает проверку API ЮKassa.
Повтор платежного события не продлевает доступ и не создаёт повторные документы/письма.
Материалы хранятся вне публичных каталогов; выдача только по активному доступу.
Документ оплаты и запись о предоставлении доступа не выдаются за подписанный акт
или фискальный чек. Шаблон акта и параметры фискализации согласуются отдельно.
