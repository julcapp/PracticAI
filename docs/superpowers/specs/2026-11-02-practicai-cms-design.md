# Встроенная CMS PracticAI

Дата: 2 ноября 2026 года. Пользователь выбрал встроенную CMS, расширяющую текущую панель.
Статус: проект на согласование; CMS ещё не установлена.

## Цель

Владелец сайта самостоятельно изменяет и дополняет PracticAI через русскоязычную панель: страницы, тексты, изображения, курсы, эксперты, меню. Существующие обращения и сценарии консультанта сохраняются.

## Подтверждённое текущее состояние

Сервер Express + MySQL на Hostland, публикация через GitHub Actions. Защищённая панель /admin уже содержит тексты, добавленные блоки, изображения, обращения и сценарии. site_content поддерживает только main/education; существующие разделы страниц в основном статические. Главный заголовок принудительно задан в site-enhancements.js, поэтому его изменение в панели сейчас не действует полностью. Курсы, шесть карточек экспертов и меню требуют изменения исходников.

## Выбранный подход и альтернативы

1. Выбрано: расширить существующую панель и базу MySQL. Сохраняются сайт, хостинг, заявки и консультант. Потребуется разработать полноценное управление содержимым.
2. WordPress: готовые инструменты редактора, но потребуется перенос страниц, темы и интеграций, отдельное сопровождение ядра и плагинов.
3. Отдельная headless CMS: потребует дополнительного сервиса и адаптации сайта, без явной пользы для текущего объёма.

## Состав первой рабочей версии

### Страницы и блоки
- Главная, «Образование» и «ИИ в работе бухгалтера» доступны для редактирования.
- Изменение заголовков, абзацев, списков, подписей, изображений и кнопок существующих разделов.
- Добавление страниц с уникальным адресом и новых типовых блоков: текст, текст с изображением, карточки, вопросы и ответы, призыв к действию.
- Порядок и видимость разделов, черновик и публикация, предпросмотр на компьютере и телефоне.
- Редактор структурированных полей; произвольные JavaScript, HTML и CSS пользователю вводить не требуется.

### Курсы
- Название, описание, программа, стоимость, правило старта, время и часовой пояс, количество занятий, срок доступа, условия оплаты.
- Для бухгалтера сохраняются утверждённые условия: 19 990 ₽; старт в первый понедельник каждого месяца; пять занятий; доступ три месяца; 17:30 по Томску; оплата 100%.
- Дни следующих занятий и итоговый документ остаются неутверждёнными.
- Опубликованные данные курса используются страницей, каталогом и тематическими ответами консультанта из одного источника.
- CMS не добавляет оплату и автоматическое зачисление: форма сохраняет запрос на запись.

### Эксперты
- Шесть существующих карточек: ФИО, должность, компетенции, описание, фото, порядок, видимость.
- Можно добавлять дополнительные карточки.
- Пока реальные данные не предоставлены, сохраняются явно обозначенные заглушки.

### Меню и общие сведения
- Подписи, адреса, порядок и видимость пунктов меню.
- Контакты и сведения об организации редактируются в отдельных полях.
- Заголовок и описание страницы для поисковых систем.
- Уже действующие формы заявок и раздел консультанта сохраняются.

### Материалы
- Загрузка PNG/JPEG/WebP через существующий механизм.
- Добавление PDF-документов до 10 МБ для сведений об организации; проверка формата, случайные имена, запрет исполнения.
- Изменение материалов не удаляет обращения или сценарии.

## Публикация и сохранность

Редактирование идёт в черновике; кнопка публикации делает выбранную редакцию доступной посетителям. Сохраняются предыдущая опубликованная редакция и возможность восстановления. Обновление кода через GitHub не перезаписывает введённое через CMS содержимое. Перед миграцией содержимого требуется восстановимая резервная копия затрагиваемых таблиц; первоначальное заполнение выполняется идемпотентно, без удаления пользовательских данных.

## Доступ и ограничения

Первый выпуск использует существующий доступ администратора. Несколько редакторов с отдельными ролями, личные кабинеты учащихся, LMS, приём платежей и визуальное изменение произвольной вёрстки не входят в этот этап. Изображения и тексты отображаются безопасно; ссылки проверяются, исполняемый код через CMS не принимается.

## Проверка и фиксация

Проверяются создание страницы, изменение существующего раздела, перестановка блоков, карточки экспертов, правка курса, единые условия в консультанте, предпросмотр, публикация и восстановление. Дополнительно: мобильное отображение, защита административных маршрутов, отсутствие потери содержимого после повторной выкладки. Изменения кода и инструкции фиксируются в GitHub; после публикации сверяется копия для GitHub Desktop на Home-Boss.

## Критерий готовности

Владелец без изменения кода меняет содержимое каждой из трёх существующих страниц, создаёт новую страницу, добавляет её в меню, редактирует курс и эксперта, смотрит предпросмотр и публикует результат. Сайт и консультант показывают одинаковые опубликованные условия курса.
